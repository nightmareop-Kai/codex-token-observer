# Codex Token Observer｜硬件 V0 产品模型

状态：外观比例冻结，显示模组与内部堆叠待实物选型后校准。

## 1. 视觉基线

- 基线来源：当前 macOS 右下角透明浮窗。
- 信息层级保持不变：顶部状态标识、`TODAY`、`TOTAL`、暗色前导零、青蓝有效数字。
- 字体锁定：Avenir Next Condensed。
- 动效锁定：机械里程表式进位；大额更新压缩为最后 12 个可读计数。
- 基线截图：`hardware-panel-visual-baseline.png`。

## 2. V0 外形尺寸

| 项目 | 目标值 | V0 工程边界 |
|---|---:|---:|
| 整机宽度 | 145 mm | 142–150 mm |
| 整机高度 | 54 mm | 52–58 mm |
| 整机厚度 | 14 mm | 首版不超过 16 mm |
| 正面圆角 | R12 mm | R10–R14 mm |
| 正面显示/透光区 | 137 × 46 mm | 随显示模组校准 |
| 桌面占地 | 145 × 54 mm | 平放或 8° 微仰支脚 |

## 3. V0 结构堆叠

从正面到背面：

1. 0.8–1.2 mm 深烟色透明面板（首版可用激光切割亚克力）。
2. 显示模组；有效显示区域居中，黑色遮光框隐藏模组边缘。
3. 主控板与 USB 数据/供电接口。
4. 3D 打印后壳，内部预留定位柱和排线空间。
5. 0.8–1.5 mm 硅胶脚垫。

## 4. 电气边界

- V0 不使用电池。
- 一根 USB-C 线完成供电与数据传输。
- 电脑端现有 Token Observer 继续负责采集 `TODAY` 和真实 `TOTAL`。
- 电脑端通过 USB 串口把两个整数发送给硬件主控。
- 视觉测试基数只存在于原型展示层，不污染真实统计数据库。

## 5. 尚未冻结的生产参数

- 屏幕技术、实际可视区、分辨率和驱动接口。
- 主控板的准确型号与 PCB 位置。
- USB-C 出线方向。
- 平放、微仰或磁吸底座方案。
- 量产外壳工艺；V0 默认 3D 打印后壳加切割面板。

在显示模组选定前，本文件是比例与结构模型，不是可直接开模的量产图纸。
