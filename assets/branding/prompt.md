# Zuno icon artwork

Local development artwork for Zuno 0.3.0. Generated with the built-in image generation tool from the user's approved seated-cat concept and a reference photo of their Maine Coon, Xiao Zhuang. The user approved the name Zuno and requested a taller Maine Coon body and an especially long, fluffy tail.

`zuno-icon.png` is the generated full-bleed source. `zuno-icon-macos.png`, `Zuno.ico`, and the app's `AppIcon.icns` are platform-packaged outputs; only scaling, safe padding and a transparent rounded mask are added during packaging. The private reference photograph is intentionally not included in this repository.

## Generation prompt

```text
Use case: precise-object-edit. Asset type: final source artwork for the Zuno desktop application icon.
Input image 1 is the APPROVED icon design to edit. Image 2 is a supporting identity reference photo of the user's actual cat Xiao Zhuang, who the user confirms is a Maine Coon.
Keep the approved C design: a complete sitting brown/grey tabby cartoon Maine Coon, head tilted in the same direction, same gentle green-gold eyes, pink nose, pale cream muzzle and mane, same dark forehead and cheek markings, same refined flat-painted illustration style, same deep muted blue-grey background.
ONLY refine the body and tail to reflect this cat: make its seated body subtly taller, longer and more substantial like a Maine Coon, with a longer rectangular torso, strong large front paws, tall tufted ears and a luxuriant chest ruff. Not a tiny round kitten. Keep the face recognizable and head size fairly large for icon recognition.
Most important: give it ONE exceptionally LONG flowing bushy plume tail, visibly much longer than in the approved image. The tail naturally emerges from behind the haunch, sweeps widely to one side, then makes a graceful long low curve around the front of the seated paws, with the tip gently curving upwards; it reads as one continuous anatomically connected long tail, not two tails or a short rounded puff. Tail arc should remain fully visible, elegantly use the lower left/right negative space, and not cover the front paws, face or chest.
Production background requirement: replace the reference's checkerboard outer area with the SAME solid muted deep blue-grey as the rest of the background, extending uniformly to ALL FOUR square canvas edges. Full-bleed square artwork, straight canvas edges: NO checkerboard, NO white border, NO inset rounded tile, NO mockup frame, NO cast shadow outside a tile, NO transparent-background simulation. Platform icon masking will be handled by the app build. Keep all ears, paws and tail inside the central 84% with safe margin so no subject is lost when rounded icon masks are applied. Square 1:1 composition.
No cake, candle, digits, name lettering, collars, props, other cats, watermarks, or background scene. Do not change the chosen style or design direction. This is a small refinement of the approved artwork, not a new character.
```
